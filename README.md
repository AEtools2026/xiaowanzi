# 小丸子岛官网

静态介绍页，**以真实界面截图为主**：首页展示「今日小本」「音乐」「收起胶囊」三张截图，已去除原截图中的深色桌面壁纸；页面本身不把任何图片当作背景图，点阵与色块均由 CSS 绘制。

功能文案对应 **小丸子岛 v2.0.5**（8 个功能页、9 类胶囊模块、6 款皮肤、Alt+Space 快捷搜索）。首页另设「快捷搜索」与「皮肤」介绍区，分别展示搜索框/设置界面和六款皮肤卡片截图。

预览：用浏览器打开 `index.html`。

下载文件放在 `downloads/`，已同步为 v2.0.5：

- `小丸子岛-win-x64.exe`
- `小丸子岛-portable.exe`
